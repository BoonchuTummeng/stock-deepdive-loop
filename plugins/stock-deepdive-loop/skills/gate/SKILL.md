# Gate — ด่านตรวจกับรายงานที่มีอยู่ (L6)

ใช้เมื่ออยากตรวจรายงานที่เขียนไว้แล้ว ไม่ว่าใครเขียน — **รับผลของ `stock-deepdive-lite` ได้ตรง ๆ**
อ่านกฎที่ `<ราก>/references/rules.md` ก่อน (`<ราก>` ดู [`ROOT.md`](../../ROOT.md)) · **เพื่อการศึกษา ไม่ใช่คำแนะนำซื้อขาย**

## หาของที่จะตรวจ
1. **รายงาน:** `./paper/<TICKER>-loop-*.html` (ผลของ loop) หรือ `./paper/<TICKER>-deepdive-*.html` (ผลของ lite) หรือ `./deepdive/<TICKER>-*.md` · หลายไฟล์ → เลือกฉบับล่าสุดแล้วบอกผู้ใช้ว่าเลือกอะไร · ไม่เจอเลย → ถามผู้ใช้ ห้ามเดา
2. **FACTS:** `./paper/<TICKER>-FACTS.md` — **ไม่มี** (รายงานที่ไม่ได้มาจาก lite/loop): เรียก agent `factcheck` สร้างก่อนจาก**เอกสารต้นฉบับในคลัง** (ไม่ใช่จากรายงาน) ถ้าเอกสารต้นฉบับก็ไม่มี → บอกตรง ๆ ว่าด่านตัวเลขจะทำได้จำกัด (ทุกตัวเลข 🟡) แล้วถามว่าจะทำต่อไหม
3. **เอกสารต้นฉบับ:** `ทุกบริษัท\<TICKER>\` และ `./paper/_work/<TICKER>/MANIFEST.md` (lite ใช้ `./data/<TICKER>/MANIFEST.md`) — ขาด MANIFEST ให้รัน `extract.py` กับโฟลเดอร์ที่มีเอกสาร
4. ประเภท thesis (moat/platform หรือไม่ → redteam จะรัน Three Deaths) — ถามหรือดูจากรายงาน

## ทำ
**เรียกด่านทั้งหมดพร้อมกันในข้อความเดียว** (ไม่ขนาน = เสียเวลาเป็นผลบวก) ผลลง `./paper/_gate/<ด่าน>-<รอบ>.md`
- **ทุกโหมด:** **critic** (รายงานอย่างเดียว) · **checker** (เปิดเอกสารต้นฉบับ — ด่านเดียวที่เปิดเต็ม) · **redteam** (เว็บอย่างเดียว) · **omission** (รายงาน + FACTS + Grep ชื่อรายการในเอกสาร)
- **โหมดเต็มเท่านั้น (ผู้ใช้ไม่ได้ขอ `quick`):** **contrarian** · **premortem** (เอกสารภายในเท่านั้น ไม่มีสิทธิ์ตัดสิน)

**รอครบทุกด่านที่เรียก** แล้วรวมข้อค้านเป็นรายการเดียว (เรียงตามความรุนแรง ตัดซ้ำ) ส่งแก้**รอบเดียว** — ผู้แก้คือ agent `writer` แก้เฉพาะจุดในไฟล์รายงาน (ถ้าเป็นรายงานของ lite ให้แก้สำเนาที่ `./paper/<TICKER>-loop-gated-<วันที่>.html` **ไม่ทับต้นฉบับ**) → ตรวจซ้ำเฉพาะจุดที่แก้
- **สูงสุด 2 รอบ** แล้วรายงานตามจริง: ข้อไหนยังไม่ผ่านและทำไม
- ห้ามแก้ข้อสรุปเงียบ ๆ ถ้าด่านชี้ว่าข้อสรุปมีปัญหา ให้รายงานผู้ใช้ตัดสินว่าจะเขียนใหม่ (กลับ `loop` L5) หรือรับป้ายกำกับ

## ส่งกลับ
- คำตัดสินแต่ละด่าน (ผ่าน / ผ่านมีเงื่อนไข / ไม่ผ่าน) และจำนวน 🟢🟡🔴
- ข้อที่ตีกลับ → แก้แล้ว / ยังไม่ผ่าน

- ตัวเลขที่ตรวจไม่ได้เพราะเอกสารไม่มี (ช่องว่างข้อมูล)
- path ไฟล์ผลตรวจทั้งหมด
