# Vault — เข้าคลัง (L8)

ใช้เมื่อมีรายงานที่**ผ่านด่านตรวจแล้ว**และอยากเก็บเข้าคลัง (หรือรันซ้ำหลังแก้รายงาน) · อ่านกฎที่ `<ราก>/references/rules.md` และแบบฟอร์มที่ `<ราก>/references/atom-template.md` (`<ราก>` ดู [`ROOT.md`](../../ROOT.md))
**เพื่อการศึกษา ไม่ใช่คำแนะนำซื้อขาย**

## เงื่อนไขก่อนเริ่ม (ไม่ครบ = หยุดและบอกผู้ใช้)
1. โปรเจกต์ปัจจุบันมี `CLAUDE.md` + `knowledge-base\` (ไม่ใช่ → เตือนและถาม)
2. มีรายงานของหุ้นนี้ `./paper/<TICKER>-*.html` และ `./paper/<TICKER>-FACTS.md`
3. **มีผลตรวจตัวเลข** `./paper/_gate/checker-*.md` — ไม่มี = ยังไม่ผ่านด่าน ⇒ **ห้ามสร้าง atom** เสนอให้รัน `gate` ก่อน (No-Verify-No-Atom)
4. ผู้ใช้ยืนยันแล้วว่าให้เข้าคลัง

## ทำ
เรียก agent **vault** พร้อมส่ง: ticker · path รายงาน · FACTS · ผล checker ฉบับล่าสุด · path ของ `references/atom-template.md` และ `rules.md`
ลำดับ: **อ่านของเดิม** (atom ที่ขึ้นต้น `<TICKER>-` · `entities/<TICKER>.md`) → atom เฉพาะ 🟢 → entity → watchlist → log

- **atom:** Insight · Implication · Quote ตรงตัว · ไฟล์+ตำแหน่ง · 🟡🔴 ไม่เป็น atom (ไปเป็นคำถามค้างใน watchlist) · ซ้ำของเดิมข้าม
- **entity:** ไม่มี → สร้างหน้าสั้น · มี → ต่อท้ายหัวข้อ "วงวิจัย <วันที่>" ไม่ทับเนื้อเดิม
- **watchlist:** คำถามค้าง + เงื่อนไขเปลี่ยนใจ แต่ละแถวต้องมี "ดูที่ไหน" ที่มีจริงและ "ดูเมื่อไหร่" เป็นวันที่/งวด
- **กลุ่มอุตสาหกรรม:** ใช้ชื่อใน `01-Topic-Map.md` เท่านั้น · ไม่มี → เสนอชื่อให้ผู้ใช้เลือกก่อน อย่าตั้งเอง
- **log.md:** ต่อท้าย 1 บรรทัด

## หลังเสร็จ
**ตรวจ Quote ด้วยสคริปต์ทุกครั้ง** (agent ตรวจตัวเองไม่พอ):
```
python "${CLAUDE_PLUGIN_ROOT}/bin/check_quotes.py" <TICKER>
```
**อ่านผลทั้งหมด ห้ามกรองด้วย head/tail และให้ดู "สรุป" บรรทัดสุดท้ายกับรหัสออก** (เคยมีเซสชันรายงานว่า "ผ่านทุก atom" จากผลที่เห็นแค่ครึ่งเดียว ทั้งที่มี atom ไม่ผ่าน) · exit 0 = ผ่านทุก atom · exit 1 = มี atom ไม่ผ่าน: `WRONG-FILE` แก้ `source_file` ให้เป็นไฟล์ที่ Quote อยู่จริง · `NOT-FOUND` / `NO-QUOTE` แก้ Quote ให้ตรงต้นฉบับ หรือ**ลบ atom นั้นออกจากคลัง**แล้วย้ายเป็นคำถามค้างใน `watchlist.md` · `NO-SOURCE` เปิดตรวจไม่ได้ ไม่ถือว่าผ่าน (แปลงไฟล์เป็น .txt ก่อน) · แก้แล้วรันซ้ำจนผ่าน อย่ารายงานว่า L8 เสร็จก่อน
อ่านกลับทุกไฟล์ยืนยันว่าลงดิสก์จริง (ไฟล์ที่ agent บอกว่าเขียนแต่ไม่มี = ทำใหม่) · รัน `loop_state.py done <TICKER> L8` ถ้ามาจากวงเต็ม
