# แบบฟอร์ม atom (ใช้โดย `vault`)

**atom = ความรู้ที่ตรวจแล้วและใช้ได้อีก 2 ปีขึ้นไป** ไม่ใช่สรุปรายงาน · เกิดได้เฉพาะจากตัวเลข/ข้อความที่ checker ให้ 🟢 และมีไฟล์+หน้า/บรรทัดต้นทาง · 🟡🔴 ห้ามเป็น atom (ไป `watchlist.md` เป็นคำถามค้าง)

ไฟล์: `knowledge-base/atoms/<TICKER>-<เลขลำดับ 2 หลัก>.md` (หาเลขถัดไปจากไฟล์ที่มีอยู่ ห้ามทับ · เขียนเป็น `.tmp` แล้วเปลี่ยนชื่อ)

```
---
ticker: <TICKER>
type: atom
status: verified
verified: 🟢
created: <YYYY-MM-DD>
source_file: <ชื่อไฟล์ในทุกบริษัท\<TICKER>\>
source_loc: <หน้า/บรรทัด/หัวข้อ>
loop: <ชื่อโฟลเดอร์ _drafts ที่มา>
---
# <TICKER>-<nn> · <ชื่อสั้นที่บอกใจความ>

**Insight:** <ข้อเท็จจริงหรือข้อสังเกตเชิงโครงสร้าง 1–3 ประโยค มีตัวเลขพร้อมหน่วยและงวด>

**Implication:** <ถ้าข้อนี้จริง มันบอกอะไรเกี่ยวกับธุรกิจ/ความเสี่ยง/สิ่งที่ต้องสังเกตต่อ — ห้ามเป็นคำแนะนำซื้อขาย>

**Quote:** "<ข้อความจากเอกสาร ยกตรงตัวอักษร>"

**Links:** [[entities/<TICKER>]] · [[sectors/<กลุ่ม จาก 01-Topic-Map>]]
```

## กฎ
- Quote ต้อง **paste ตรงตัว** ห้ามแปลงหรือสรุป · ถ้าเอกสารเป็นภาษาอังกฤษ ยกอังกฤษตามต้นฉบับ
- ซ้ำกับ atom เดิม (ใจความเดียวกัน ตัวเลขเดียวกัน) → ไม่สร้างใหม่ ให้เพิ่ม `Links` ไปที่ atom เดิมถ้าจำเป็น
- กลุ่มอุตสาหกรรมที่ไม่อยู่ใน `01-Topic-Map.md` → เสนอชื่อแล้วถามผู้ใช้ ห้ามตั้งเอง
- ตัวเลขที่ผู้เขียนคำนวณเอง ต้องมีวิธีคิดใน Insight และติด `[คำนวณ]`

# รูปแบบแถว `watchlist.md` (คำถามค้าง + เงื่อนไขเปลี่ยนใจ)
```
- [<TICKER>] <คำถามค้าง หรือ เงื่อนไขเปลี่ยนใจที่วัดได้> · ดูที่: <เอกสาร/ตัวเลขที่จะบอกได้ และ**ต้องมีจริง**> · ดูเมื่อ: <YYYY-MM-DD หรือ งวดงบ> · สถานะ: เปิด
```
เงื่อนไขเปลี่ยนใจต้องผูกกับ **ตัวแปรที่ทำลายเหตุผลของ thesis ได้จริง** และมีแหล่งที่ยิงได้ (เอกสารที่บริษัทต้องเปิดเผย) — ห้ามตั้งเงื่อนไขที่อ้างตัวเลขที่บริษัทไม่เคยเปิดเผย
