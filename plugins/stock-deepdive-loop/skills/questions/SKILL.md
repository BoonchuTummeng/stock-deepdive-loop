อ่านกฎที่ `<ราก>/references/rules.md` และธนาคารคำถามที่ `<ราก>/references/question-bank.md` ก่อน (`<ราก>` ดู [`ROOT.md`](../../ROOT.md))

## เตรียม
1. ตรวจว่าโปรเจกต์ปัจจุบันมี `CLAUDE.md` + `knowledge-base\` (ไม่ใช่ → เตือนและถาม)
2. หาโฟลเดอร์ `ทุกบริษัท\<TICKER>\` จาก CLAUDE.md ของผู้ใช้ — **ไม่มีเอกสารในชั้นบน = ห้ามเริ่ม** บอกให้ใช้ `/new-stock <TICKER>` หรือสั่ง `loop` เพื่อให้ collector เก็บก่อน
3. มี `knowledge-base/_drafts/loop-<TICKER>/idea-card.md` ไหม — มี: ใช้คำถามเปิดและประเภท thesis จากการ์ด · ไม่มี: ถามผู้ใช้ 1 ข้อว่าประเด็นหลักที่อยากรู้คืออะไร และประเภท thesis (หรือเดาจากธุรกิจแล้วบอกว่าเดา)
4. ลอง `nlm notebook list` — ผ่าน: ใช้ notebook "<TICKER>" · **ไม่ผ่าน (ไม่มีคำสั่ง / login หมดอายุ) ต้องแจ้งผู้ใช้ ไม่ข้ามเงียบ ๆ:** บอกสาเหตุที่เห็นจริง + วิธีแก้ (เปิดเทอร์มินัลพิมพ์ `nlm login` เข้าด้วยบัญชี Google ที่ใช้กับ NotebookLM · ถ้า login ไม่ผ่านให้ปิด Chrome ทุกหน้าต่างก่อนแล้วลองใหม่ · ไม่มีคำสั่ง nlm = ยังไม่ได้ติดตั้งตาม Day 1) แล้วให้ผู้ใช้เลือก (1) login แล้วลองใหม่ (2) ทำต่อด้วยโหมดอ่านเอง ซึ่งตื้นกว่าและช้ากว่า · ถ้า `nlm` ล้มกลางทาง ใช้ข้อความเดียวกัน

## ลำดับ
ชั้น 0 เปิดเรื่อง → **ชั้น 1 blind-spot 3 ข้อ (บังคับ)** → ชั้น 2 forensic เลือกเฉพาะที่ตรงกับอาการของหุ้นนี้ → ชั้น 3 framework lens ตามชนิด thesis (1–2 ชุด) → คำถามเปิดจากการ์ด
- **ขนานได้ครั้งละไม่เกิน 3 ข้อ** ข้อที่พึ่งคำตอบก่อนหน้ายิงเรียงและบอกเหตุผล
- **ทุกคำตอบ** บันทึกลง `knowledge-base/notebooklm-qa/<TICKER>.md` ทันที (คำถาม · คำตอบ · แหล่ง · วันที่ · ใช้ notebook หรืออ่านเอง) ต่อท้ายไฟล์เดิม ไม่ทับ

## โหมดอ่านเอง (ไม่มี nlm)
ตอบจากไฟล์ `.txt` ในชั้นบนด้วย Grep (ไฟล์ใหญ่ห้ามอ่านทั้งเล่ม) ทุกคำตอบมี `ไฟล์:บรรทัด` และป้าย `[อ่านเอง ไม่ผ่าน notebook]` · หน้าที่เป็นภาพสแกนตาม `MANIFEST.md` ให้เปิดด้วย Read ระบุ pages · ตอบไม่ได้เพราะเอกสารไม่มี = เขียนว่า "เอกสารที่มีไม่ตอบข้อนี้" ไม่เดา

## หลักการอ่านคำตอบ
- คำตอบจาก notebook/การอ่านเอง = **คำอ้างที่มีแหล่ง** ยังไม่ใช่ตัวเลขที่ตรวจแล้ว (checker จะตรวจใน L6) — ห้ามมีคำสรุปว่า "ยืนยันแล้ว"
- ตัวเลขย้อนหลัง/ guidance ที่ notebook ให้ ต้องไปเปิดเอกสารยืนยันก่อนใช้เป็นตัวเลขหลัก
- ข้อไหนคำตอบขัดกันเอง บันทึกทั้งสองฝั่ง อย่าเลือกข้างเงียบ ๆ
