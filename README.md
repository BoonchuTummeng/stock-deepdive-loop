# Stock DeepDive Loop

วงวิจัยหุ้นครบวง L0–L8 ที่ต่อจากโปรเจกต์ MyStock และเขียนผลกลับเข้าคลังความรู้ (atom · entity · watchlist) — สำหรับ Claude Code และ Codex

```
/plugin marketplace add BoonchuTummeng/stock-deepdive-loop
/plugin install stock-deepdive-loop@boonchu-loop
```

รายละเอียด วิธีใช้ ขีดจำกัด และเวลา/โควตา: [plugins/stock-deepdive-loop/README.md](plugins/stock-deepdive-loop/README.md)
