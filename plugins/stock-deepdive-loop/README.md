# Stock DeepDive Loop — วงวิจัยหุ้นครบวง เข้าคลังความรู้

ปลั๊กอินคู่กับ `stock-deepdive-lite` (อยู่คนละ repo ใช้ร่วมกันได้ ไม่ชนกัน)
lite ให้ **รายงานหนึ่งฉบับ** · loop ให้ **วงวิจัยครบ แล้วไหลกลับเข้าคลัง MyStock ของคุณ** — atom ที่ตรวจแล้ว หน้าหุ้น และ watchlist ของคำถามค้างกับเงื่อนไขเปลี่ยนใจ

> **เพื่อการศึกษา ไม่ใช่คำแนะนำซื้อขาย** — ปลั๊กอินนี้ไม่ให้ราคาเป้า ไม่ให้ช่วงเข้าซื้อ ไม่ให้ขนาดไม้ และไม่บอกให้ซื้อหรือขาย

## ต้องมีอะไรก่อน
1. โปรเจกต์ `MyStock\` ที่ทำตาม Day 1–2 แล้ว (มี `CLAUDE.md` และ `knowledge-base\` — ถ้าเปิดในโฟลเดอร์อื่น ปลั๊กอินจะเตือนและถามก่อน ไม่สร้างโครงเอง)
2. คลังเอกสาร `C:\ทุกบริษัท\` (Mac: `~/ทุกบริษัท/`) และคำสั่ง `/new-stock` จาก Day 1
3. Python 3 (ไลบรารีมาตรฐานก็พอ · `pymupdf` หรือ `pypdf` ช่วยแปลง PDF ได้ ไม่บังคับ · `yt-dlp` เฉพาะถ้าอยากให้ดึงเทป Oppday อัตโนมัติ)
4. หุ้นสหรัฐ: ตั้งตัวแปรสภาพแวดล้อม `SEC_CONTACT` เป็นอีเมลของคุณ (SEC กำหนดให้ระบุตัวตนผู้ดึงข้อมูล)
5. ควรมี: `nlm` (NotebookLM CLI) ที่ login แล้ว — ถ้าเรียกไม่ได้ ระบบจะ**แจ้งให้คุณ `nlm login`** แล้วถามว่าจะลองใหม่หรือทำต่อแบบ "อ่านเองจากไฟล์" (ตื้นกว่าและช้ากว่า มีป้ายบอกชัดเจน) · ราคา/PE: ต่อ TradingView MCP ทางการได้ ถ้าไม่ต่อจะถามคุณหรือเขียนว่า "ไม่มีข้อมูลราคา"

ห้ามใส่รหัสลับ (API key, รหัสผ่าน, ข้อมูลล็อกอิน) ลงในไฟล์ของปลั๊กอินหรือในโปรเจกต์ที่จะเผยแพร่

## ใช้ยังไง
| คำสั่ง | ทำอะไร |
|---|---|
| `/stock-deepdive-loop:loop <TICKER>` | ทั้งวง L0–L8 · หยุดถามคุณ 2 จุด (อนุมัติแผน · ก่อนเข้าคลัง) · เติม `quick` = ข้ามสามฉาก แก้ 1 รอบ |
| `/stock-deepdive-loop:questions <TICKER>` | คำถาม 4 ชั้นกับเอกสาร (L3) อย่างเดียว |
| `/stock-deepdive-loop:gate <TICKER>` | ส่งรายงานที่มีอยู่ผ่านด่านตรวจ (L6) — **ใช้กับผลของ lite ได้** |
| `/stock-deepdive-loop:vault <TICKER>` | เข้าคลังอย่างเดียว (L8) |

```
L0 อ่านคลังเดิม → L1 การ์ดไอเดีย+แผนแหล่ง (🛑 รออนุมัติ) → L2 เก็บเอกสาร → L3 คำถาม 4 ชั้น
→ L4 FACTS+SPINE → L5 เขียนเป็นคลื่น (ขนาน) → L6 ด่านตรวจ 4–6 ด่านขนาน → L7 เย็บ HTML (🛑 ก่อนเข้าคลัง) → L8 เข้าคลัง
```
งานค้างกลางทางเก็บที่ `knowledge-base/_drafts/loop-<TICKER>/` · รันซ้ำหุ้นเดิม = ข้ามขั้นที่เสร็จแล้ว (และไฟล์ผลยังอยู่) ไม่ทับไฟล์ ไม่สร้าง atom ซ้ำ

## เวลาและโควตา (โดยประมาณ — ยังต้องวัดจริงบนเครื่องคุณ)
- วงเต็ม ~60–90 นาที/หุ้น · `quick` สั้นกว่า
- ส่วนที่กินโควตามากที่สุดคือ L5 (เขียนขนานหลายตัว) และ L6 (ด่านตรวจขนาน 4 ด่าน หรือ 6 ด่านในโหมดเต็ม โดย 3 ตัวใช้ model แรง) · **แผน Pro แนะนำให้เริ่มด้วย `quick`** (4 ด่าน) แล้วค่อยรันโหมดเต็มกับหุ้นที่สนใจจริง
- แผน Pro: ถ้าโควตาหมดกลางวง ให้รอรีเซ็ตแล้วสั่งใหม่ — ระบบทำต่อจากขั้นที่ค้าง
- เปลี่ยน model ได้ที่บรรทัด `model:` ในหัวไฟล์ `agents/*.md` (ค่าเริ่มต้น: critic · redteam · contrarian = opus, ที่เหลือ = sonnet)

## เทปประชุมนักลงทุน (Oppday) — หุ้นไทย ดึงอัตโนมัติ
ขั้น L2 หาคลิป Opportunity Day 2 งวดล่าสุดของหุ้นจากช่อง YouTube ทางการ **SET Thailand** แล้วดึง **คำบรรยาย (subtitle) ของคลิป** เก็บเป็นไฟล์ `.txt` ในคลังหุ้น (ไม่ทับของเดิม) และเพิ่มเข้า notebook ให้ถ้ามี `nlm`
- ต้องติดตั้ง `yt-dlp` หนึ่งครั้ง: `python -m pip install -U yt-dlp` (ไลบรารีภายนอกตัวเดียวของปลั๊กอิน · ถ้ายังไม่มี ระบบจะถามก่อนติดตั้ง · YouTube เปลี่ยนบ่อย ถ้าดึงไม่ได้ให้อัปเดตด้วยคำสั่งเดิม)
- ติดตั้งไม่ได้/ไม่อยากติดตั้ง: ทางสำรองคือให้ NotebookLM รับคลิปโดยตรง หรือ **ใช้ Obsidian Web Clipper คลิปหน้าคลิปลง `knowledge-base
aw\` ตามที่เรียนมา แล้วพิมพ์ "ต่อ"** — ระบบคัดแยกเข้าโฟลเดอร์หุ้นให้เอง

**หลักทั้งปลั๊กอิน:** อะไรดึงอัตโนมัติได้ ระบบดึงให้ · ดึงไม่ได้ ระบบจะบอกตรง ๆ ว่าต้องไปเอาอะไร จากที่ไหน แล้วให้ใส่ที่ `knowledge-base
aw\` (Web Clipper หรือโหลดเอง) ระบบจะย้ายเข้า `ทุกบริษัท\<TICKER>\` ให้ตามกติกาคลังหุ้น
- ได้: คำพูดผู้บริหาร + ช่วงถามตอบ ที่งบไม่มี
- **เสียงถอดอัตโนมัติ (ASR)**: ตัวเลขห้ามใช้ตรงต้องเทียบงบ · ชื่อคนอาจเพี้ยน · ถือเป็น "คำอ้างผู้บริหาร"
- หน้า YouTube เปลี่ยนโครงได้โดยไม่แจ้ง — ถ้าหาคลิปไม่เจอ ระบบจะบอกให้เปิดช่อง SET Thailand หาเอง (ไม่เดา URL)
- ไม่มี `nlm`: ได้รายการ URL + วิธีคัดลอกข้อความถอดเสียงมือ (กด "แสดงข้อความถอดเสียง" ใต้คลิป)
- หุ้นสหรัฐ: ขั้นนี้ไม่ทำ (ใช้ transcript ที่มีแหล่งทางการหรือคนถอด)

## ขีดจำกัด
- ดึงเอกสารอัตโนมัติได้เฉพาะ ก.ล.ต. iDisc (หุ้นไทย) และ SEC EDGAR (หุ้นสหรัฐ) · เทป Oppday ดึงจาก YouTube ช่อง SET Thailand (หุ้นไทย) ที่อื่นต้องโหลดเอง (ปลั๊กอินจะทำรายการให้)
- PDF ที่เป็นภาพสแกนอ่านด้วยตาของ Claude ทีละไม่เกิน 20 หน้า — ช้ากว่าและแม่นน้อยกว่าไฟล์ข้อความ
- ด่านตรวจลดโอกาสผิดพลาด **ไม่ใช่การรับประกันว่าถูก** — ตัวเลขสำคัญควรเปิดเอกสารยืนยันเอง
- ไม่มี valuation model เป็นสเปรดชีต ไม่ติดตาม portfolio ไม่ส่งคำสั่งซื้อขาย
