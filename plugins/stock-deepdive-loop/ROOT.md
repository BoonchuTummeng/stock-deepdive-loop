# `<ราก>` คืออะไร และหาอย่างไร

ไฟล์ในปลั๊กอินนี้อ้างถึงสคริปต์และไฟล์กฎด้วย path แบบ `<ราก>/bin/...` และ `<ราก>/references/...`

> **`<ราก>` = โฟลเดอร์ปลั๊กอินที่มี `bin/` กับ `skills/` อยู่ด้วยกัน**

ปลั๊กอินนี้รองรับ **Claude Code เท่านั้น** (ไม่รองรับ Codex)

## หาอย่างไร
ในข้อความของ skill คำสั่งเขียนด้วย `${CLAUDE_PLUGIN_ROOT}` ซึ่งถูกแทนเป็น path จริงตอนโหลด skill — ให้จด path จริงนั้นไว้
- ตัวแปรนี้ **ไม่มีอยู่ใน environment ของ Bash** และ **agent ย่อยไม่รู้จัก `<ราก>`** — ต้องส่ง path เต็มของ `bin/` และ `references/` ให้ agent ย่อยในทุก prompt
- ถ้า clone repo มาใช้ตรง ๆ (ไม่ผ่านระบบปลั๊กอิน) `<ราก>` คือ `plugins/stock-deepdive-loop/` ใน repo ที่ clone มา

## ตรวจหนึ่งครั้งก่อนเริ่มงานจริง
```
python "<path จริง>/bin/extract.py" --help
```
ผ่าน = หาถูก · **error = หาผิด ให้หาใหม่ ห้ามเดาต่อ**
