# ไอเดีย — การ์ด + แผนแหล่งข้อมูล (L1)

ผู้เรียกจะส่งมาให้: ticker · path ของโฟลเดอร์ `ทุกบริษัท\<TICKER>\` · สรุปสิ่งที่คลังเดิมมี (จาก L0) · path ของ `references/`

## ทำอะไร
1. **คำถามกลาง 1 ข้อ** — คำถามที่ถ้าตอบได้จะเปลี่ยนความเข้าใจต่อธุรกิจนี้ (เช่น "กำไรโตเพราะปริมาณหรือราคา และยั่งยืนไหม") ห้ามเป็นคำถามว่าซื้อหรือขาย
2. **สมมติฐาน** — ข้อที่คิดว่าจริง + สิ่งที่ถ้าเจอจะหักล้างมัน (ระบุว่าจะไปหาที่ไหน) ทุกสมมติฐานคือ "สมมติฐาน" ไม่ใช่ข้อเท็จจริง
3. **คำถามเปิด 5–8 ข้อ** — เรียงตามว่าคำตอบจะเปลี่ยนภาพมากแค่ไหน (ข้อที่คำตอบไม่เปลี่ยนอะไรไม่ต้องใส่)
4. **ทำไมตอนนี้** — มีอะไรที่สังเกตได้ในช่วง 6–18 เดือน ที่ทำให้เรื่องนี้ควรดูตอนนี้ ตอบไม่ได้ให้เขียนว่ายังไม่มี
5. **ประเภทของ thesis** (เติบโต/ผู้บริโภค/moat/คอขวด/ถูกดิสรัปต์/โครงสร้างพื้นฐาน/อื่น ๆ) เพื่อเลือกชุดคำถามชั้น 3
6. **แผนแหล่งข้อมูล** 3 กลุ่ม — 🟢 มีในเครื่องแล้ว (ระบุไฟล์) · 🟡 ต้องดึง (งบ 4 ไตรมาส MD&A 56-1 หรือ 10-K/10-Q ที่ขาด) · 🔴 ต้องให้ผู้ใช้โหลดเอง (ระบุลิงก์/ที่ไปหา) ห้ามเดาว่ามีไฟล์ที่ไม่มี

### ข้อควรระวังตอนทำแผนแหล่ง
- **ดูโฟลเดอร์หุ้นที่เกี่ยวข้องในคลังด้วย** (บริษัทลูก/แม่/ผู้ถือหุ้นใหญ่ที่เป็นหุ้นจดทะเบียน เช่น ถ้าธุรกิจหลักมีบริษัทลูกที่ถือเป็นก้อนใหญ่) ดูด้วย `ls` ว่ามี `ทุกบริษัท\<TICKER อื่น>\` ไหมและมีอะไร — ถ้ามี ให้ใส่เป็น 🟢/🟡 พร้อมบอกว่ามีเอกสารชนิดใด (งบ หรือแค่ transcript) แทนที่จะลง 🔴 "ต้องโหลดเอง" โดยไม่เช็ก
- **ราคา/มูลค่าตลาด:** ใส่ว่า "ถ้ามีแหล่งราคา (เช่น TradingView MCP ทางการ) จะดึงใน L4 · ไม่มี → จะถามผู้ใช้หรือเขียนว่าไม่มีข้อมูลราคา" **ห้ามเขียนเหมือนผู้ใช้มีเครื่องมือราคาอยู่แล้ว**
- **ตัวเลขในการ์ด** ที่มาจากเอกสารเดียวที่เป็นเสียงผู้บริหาร (เช่น สรุป Oppday) ติดป้าย "คำอ้างผู้บริหาร รอ factcheck" ทุกตัว และเมื่อสมมติฐานข้อใดตั้งต้นจากกรอบของผู้บริหาร ให้ระบุไว้ว่า "กรอบนี้มาจากผู้บริหาร"
- เพิ่มคำถามเปิด 1 ข้อเสมอ: **กำไร/การเติบโตที่เห็นมีรายการครั้งเดียวหรือรายได้อื่นปนอยู่เท่าไร** (ก่อนเชื่ออธิบายที่ว่าโตจากการดำเนินงาน)
