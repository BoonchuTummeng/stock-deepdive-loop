> Claude Code อ่านไฟล์นี้ผ่าน `CLAUDE.md` ที่เขียนว่า `@AGENTS.md` · Codex อ่าน `AGENTS.md` ตรง ๆ

## กฎที่ห้ามผ่อน ไม่ว่าจะเรียกด้วยเครื่องมือไหน

1. **ตัวเลขเข้ารายงานได้ทางเดียว — ผ่าน `FACTS.md`** คนเขียนห้ามเปิดเอกสารต้นฉบับหยิบตัวเลขเอง
2. **ห้ามเริ่มเขียนถ้าไม่มีเอกสารต้นฉบับ** — ดึงไม่ได้ให้บอกว่าติดตรงไหนแล้วถาม ห้ามเขียนจากความจำแล้วทำเหมือนมีหลักฐาน
3. **แยกชั้นความน่าเชื่อถือ** — เอกสารที่ยื่น ≠ คำพูดผู้บริหาร ≠ พาดหัวข่าว ≠ ข้อมูลตลาดแหล่งรอง
4. **ข้อมูลที่ไม่มี ต้องเขียนว่าไม่มี** ห้ามเว้น ห้ามเดาแทน
5. **เจอความผิดปกติ ≠ พิสูจน์เจตนา**
6. **เพื่อการศึกษา ไม่ใช่คำแนะนำการลงทุน** — ห้ามบอกให้ซื้อ/ขาย ห้ามราคาเป้า ห้ามช่วงราคาเข้าซื้อ ห้ามขนาดไม้ และห้ามชี้นำอ้อมผ่านการเรียงลำดับฉาก
7. **No-Verify-No-Atom** — เข้าคลังเป็น atom ได้เฉพาะสิ่งที่ตรวจแล้ว 🟢 · 🟡🔴 = คำถามค้างใน `watchlist.md`
8. **ชั้นบนของ `ทุกบริษัท\<TICKER>\` เขียนได้เฉพาะไฟล์ใหม่** — ห้าม Edit / Write ทับไฟล์ที่มีอยู่ (`_analysis\` · `_reference\` · `notebooks-index.md` แก้ได้)
9. **ตรวจไฟล์ที่เขียนว่าลงดิสก์จริง** ก่อนรายงานว่าเสร็จ

## งานที่ต้องใช้สคริปต์ ห้ามให้ AI ทำแทน
หาคลิป Oppday (`find_oppday.py`) · ดึงคำบรรยาย (`oppday_subs.py`) · แกะไฟล์ · แปลง PDF · หาหน้าสแกน · ประกอบ HTML · ตรวจ Quote ของ atom (`check_quotes.py`) · ตรวจว่าตัวเลขหลุดจาก `FACTS.md` · อ่าน/เขียนสถานะวง ⇒ `bin/` ถืออยู่แล้ว

## แก้ไขปลั๊กอินนี้
เนื้อมีชุดเดียว manifest มีสองชุด (`.claude-plugin/` · `.codex-plugin/`) — 🔴 **ห้ามใส่ path หรือตัวแปรที่ผูกกับเครื่องมือใดเครื่องมือหนึ่ง** (เช่น `${CLAUDE_PLUGIN_ROOT}`) ลงใน `skills/` `agents/` `references/` ให้เขียน `<ราก>` แล้วอธิบายวิธีหาไว้ใน `ROOT.md` ที่เดียว (ข้อยกเว้นเดียว: บรรทัดคู่ "Claude Code / Codex" ในช่องคำสั่ง ตามรูปแบบของ lite)
