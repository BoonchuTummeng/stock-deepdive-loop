# เลนส์ตีมูลค่า (สำหรับหัวข้อมูลค่า — กรอบ "ราคานี้บังคับให้เชื่ออะไร")

ห้ามให้ราคาเป้า ห้ามช่วงราคาเข้าซื้อ ห้ามขนาดไม้ — เป้าหมายคือ **เห็นว่าราคาปัจจุบันฝังความเชื่ออะไรไว้ และความเชื่อนั้นต้องเป็นจริงข้อไหนบ้าง**
ตีอย่างน้อย 3 เลนส์ แล้ว **ชี้จุดที่เลนส์ขัดกัน** (จุดนั้นคือความไม่แน่นอนหลัก)

1. **กำไรเจ้าของ / กระแสเงินสดอิสระ** — กำไรที่ปรับรายการไม่เป็นเงินสดแล้ว (owner earnings หรือ FCF) ต่อมูลค่าตลาด · ใช้ค่าเฉลี่ยหลายปีถ้าวัฏจักรแรง
2. **เงินปันผลและการจ่ายออก (ถ้าจ่าย)** — เงินปันผลมาจากกระแสเงินสดจริงไหม ถ้าบริษัทมีบริษัทลูกต่างประเทศ ตรวจว่าเงินสดเอากลับมาได้จริงไหม
3. **สินทรัพย์ / SOTP** — มูลค่าแต่ละส่วนธุรกิจหรือสินทรัพย์ แล้วหักส่วนลดตามจริง (โครงสร้างถือหุ้น ข้อจำกัดนำเงินออก)
4. **Reverse-DCF** — ที่ราคานี้ รายได้ต้องโตปีละเท่าไร margin ต้องไปถึงเท่าไร นานกี่ปี จึงจะได้ผลตอบแทนเท่าต้นทุนเงินทุน · เทียบกับสิ่งที่บริษัททำได้จริงในอดีต

## กฎความสอดคล้อง (ตรวจก่อนส่ง)
- การเติบโตต้องมีการลงทุนรองรับ (โตเร็วแต่ไม่ลงทุนเพิ่ม = ไม่สอดคล้อง)
- อัตราโตระยะยาวไม่เกินอัตราดอกเบี้ยไร้ความเสี่ยงของสกุลเงินเดียวกัน
- ใช้สกุลเงินเดียวตลอดสมการ (กระแสเงินสดบาทใช้อัตราคิดลดบาท)
- ตัวขับระยะใกล้ทุกตัวต้องผูกกับบรรทัดในงบหรือคำพูดผู้บริหารที่ระบุแหล่ง

## ถ้าอ้างมุมมองต่างจากตลาด (variant)
ต้องแตกให้เห็นว่าต่างตรงไหน: กำไรต่อหุ้น / multiple / เวลา · ประมาณการนักวิเคราะห์รายเดียวที่ไม่มีที่มา ห้ามใช้เป็นฐาน · ติดป้ายแหล่งและวันที่ทุกครั้งที่ใช้ตัวเลขตลาด

## ไม่มีข้อมูลราคา
เขียนตรง ๆ ว่า "ไม่มีข้อมูลราคา" แล้วทำเลนส์ที่ไม่ต้องใช้ราคา (คุณภาพกำไร กระแสเงินสด สิ่งที่ธุรกิจต้องทำให้ได้) อย่าเดาราคา
